Panduan pemasangan (sekali saja)
  1. Buat Google Sheet baru, lalu buka Extensions > Apps Script.
  2. Hapus isi bawaan, tempel seluruh isi file Code.gs, lalu Save.
  3. Disarankan: isi KUNCI di baris atas kode dengan kata sandi singkat.
  4. Deploy > New deployment > Web app. Execute as Me, Who has access Anyone. Klik Deploy dan setujui izin.
  5. Salin Web app URL (berakhiran /exec), tempel di kolom atas, klik Hubungkan. Ulangi di tiap perangkat, atau isi SCRIPT_URL di bagian atas skrip file ini agar otomatis aktif di semua perangkat.
